
# Aplicacion de App Festejos

Esta es una aplicacion de Reportes de seguimiento, esto hara que se le continuidad 
a los problemas que reporta el cliente al personal de Ruta o a los numeros de atencion a cliente de la agencia de Corona los Tuxtlas.
